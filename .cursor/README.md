# دليل تكوين Cursor لمشروع Arkan

## نظرة عامة
هذا المجلد يحتوي على تكوينات Cursor المخصصة لمشروع Arkan، بما في ذلك القواعد والأوامر والموارد.

## هيكل المجلد

```
.cursor/
├── README.md                    # هذا الملف
├── environment.json             # إعدادات البيئة
├── rules/                       # قواعد Cursor
│   ├── user-preferences.mdc     # قواعد المستخدم والتفضيلات
│   ├── قاعدة بنك الذاكرة المحسنة.mdc
│   ├── قاعدة إضافي للعمل اليومي.mdc
│   └── ...                      # قواعد أخرى
├── commands/                    # أوامر مخصصة
│   ├── UserPreferences/         # أوامر قواعد المستخدم
│   ├── ai/                      # أوامر الذكاء الاصطناعي
│   ├── Analysis/                # أوامر التحليل
│   └── ...                      # أوامر أخرى
└── resources/                   # موارد خارجية (اختياري)
```

## الملفات الأساسية

### 1. AGENTS.md (في جذر المشروع)
يحدد قواعد المستخدم العامة والتفضيلات لوكيل Cursor:
- أسلوب التواصل المفضل
- قواعد الترميز
- تفضيلات المشروع
- معايير الجودة
- أنماط التطوير

### 2. .cursor/rules/user-preferences.mdc
يطبق قواعد المستخدم على جميع التفاعلات مع وكيل Cursor.

### 3. .cursor/commands/
يحتوي على أوامر مخصصة لتنفيذ مهام محددة.

## كيفية الاستخدام

### 1. تطبيق قواعد المستخدم
```
استخدم الأمر: "طبق قواعد المستخدم المحددة في AGENTS.md"
```

### 2. استخدام الأوامر المخصصة
```
استخدم الأوامر المحددة في مجلد commands/:
- أوامر الذكاء الاصطناعي
- أوامر التحليل
- أوامر التطوير
- أوامر الاختبار
```

### 3. تطبيق القواعد المتخصصة
```
استخدم القواعد المحددة في مجلد rules/:
- قواعد TypeScript

- قواعد Next.js
- قواعد Tailwind CSS
```

## قواعد المستخدم الرئيسية

### أسلوب التواصل
- **اللغة**: العربية (أساسية) + الإنجليزية (تقنية)
- **الأسلوب**: مهني، ودود، ومفصل
- **الهيكل**: خلاصة + تفاصيل + بدائل + خطوات تالية

### قواعد الترميز
- **اللغة**: TypeScript الصارم
- **التنسيق**: ESLint + Prettier
- **التعليقات**: JSDoc للدوال العامة
- **الأسماء**: meaningful names باللغة الإنجليزية

### تفضيلات المشروع
- **الهيكل**: modular و component-based
- **التسمية**: PascalCase للمكونات، camelCase للدوال
- **الجودة**: اختبارات + توثيق + أداء + أمان

## الأوامر المتاحة

### أوامر التطوير
- `createComponent` - إنشاء مكون جديد
- `createHook` - إنشاء hook مخصص
- `createPage` - إنشاء صفحة جديدة
- `completeFeature` - إكمال ميزة

### أوامر الذكاء الاصطناعي
- `createAiFlow` - إنشاء تدفق AI جديد
- `ImproveAiflow` - تحسين تدفق AI موجود

### أوامر التحليل
- `Code analysis` - تحليل الكود
- `Architectural Review` - مراجعة المعمارية

### أوامر الاختبار
- `createTest` - إنشاء اختبارات
- `runTest` - تشغيل الاختبارات

### أوامر الأمان
- `SecurityReview` - مراجعة الأمان
- `UpdateDependencies` - تحديث التبعيات

## نصائح للاستخدام الأمثل

### 1. اقرأ بنك الذاكرة أولاً
```
ابدأ كل جلسة بقراءة بنك الذاكرة لفهم السياق الحالي
```

### 2. استخدم القواعد المناسبة
```
اختر القواعد المناسبة للمهمة:
- قواعد عامة للتطوير اليومي
- قواعد متخصصة للمهام المعقدة
- قواعد الذكاء الاصطناعي للـ AI features
```

### 3. طبق معايير الجودة
```
تأكد من تطبيق معايير الجودة:
- اختبارات شاملة
- توثيق مفصل
- أداء محسن
- أمان قوي
```

### 4. استخدم الأوامر المخصصة
```
استخدم الأوامر المخصصة لتنفيذ المهام بكفاءة:
- أوامر التطوير للميزات الجديدة
- أوامر التحليل للمشاكل المعقدة
- أوامر الاختبار لضمان الجودة
```
