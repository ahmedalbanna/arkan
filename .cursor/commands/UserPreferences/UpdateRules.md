# تحديث قواعد المستخدم

## نظرة عامة
هذا الأمر يساعد في تحديث قواعد المستخدم المحددة في `AGENTS.md` حسب احتياجات المشروع المتطورة.

## كيفية التحديث

### 1. تحديث قواعد التواصل
```
حدث قواعد التواصل في AGENTS.md:
- أضف تفضيلات جديدة للغة
- حدث أسلوب التواصل
- أضف معايير جديدة للردود
- حدث هيكل الردود المطلوب
```

### 2. تحديث قواعد الترميز
```
حدث قواعد الترميز في AGENTS.md:
- أضف معايير جديدة للكود
- حدث أنماط التطوير
- أضف قواعد جديدة للـ TypeScript
- حدث قواعد React
```

### 3. تحديث قواعد المشروع
```
حدث قواعد المشروع في AGENTS.md:
- أضف تفضيلات جديدة للمشروع
- حدث هيكل المجلدات
- أضف أنماط تسمية جديدة
- حدث معايير الجودة
```

## أمثلة على التحديثات

### مثال 1: إضافة قاعدة جديدة
```
أضف قاعدة جديدة لقواعد الترميز:
- استخدم const assertions للقيم الثابتة
- استخدم readonly للخصائص غير القابلة للتعديل
- استخدم satisfies operator للتحقق من الأنواع
```

### مثال 2: تحديث قاعدة موجودة
```
حدث قاعدة TypeScript الموجودة:
- بدلاً من تجنب any، استخدم unknown أولاً
- أضف التحقق من الأنواع في runtime
- استخدم branded types للأنواع المميزة
```

### مثال 3: إضافة قاعدة للذكاء الاصطناعي
```
أضف قاعدة جديدة للذكاء الاصطناعي:
- استخدم streaming للاستجابات الطويلة
- طبق rate limiting للطلبات
- أضف retry logic للأخطاء المؤقتة
- استخدم caching للاستجابات المتكررة
```

## عملية التحديث

### 1. مراجعة القواعد الحالية
```
راجع القواعد الحالية في AGENTS.md:
- حدد القواعد التي تحتاج تحديث
- حدد القواعد الجديدة المطلوبة
- حدد القواعد التي لم تعد مناسبة
```

### 2. تحديث القواعد
```
حدث القواعد المحددة:
```

### 3. اختبار التحديثات
```
اختبر التحديثات الجديدة:
- طبق القواعد على مهام حقيقية
- تحقق من فعالية القواعد
- راجع النتائج مع الفريق
- عدل القواعد حسب الحاجة
```

### 4. توثيق التحديثات
```
وثق التحديثات:
- اذكر سبب التحديث
- اشرح القواعد الجديدة
- أضف أمثلة على الاستخدام
- حدث دليل الاستخدام
```

## مراقبة فعالية القواعد

### مؤشرات الأداء
- **جودة الكود**: تحسن في جودة الكود المولد
- **سرعة التطوير**: زيادة في سرعة التطوير
- **دقة الحلول**: تحسن في دقة الحلول المقترحة
- **رضا المطورين**: تحسن في رضا الفريق

### مؤشرات المشاكل
- **تعارض القواعد**: قواعد متضاربة
- **قواعد معقدة**: قواعد صعبة التطبيق
- **قواعد غير فعالة**: قواعد لا تحسن النتائج
- **قواعد قديمة**: قواعد لم تعد مناسبة

## نصائح للتحديث الفعال

### 1. تحديث تدريجي
- حدث القواعد تدريجياً
- اختبر كل تحديث قبل الانتقال للتالي
- اجمع التغذية الراجعة من الفريق
- عدل القواعد حسب الحاجة

### 2. توثيق شامل
- وثق سبب كل تحديث
- أضف أمثلة واضحة
- اشرح كيفية التطبيق
- وثق الاستثناءات

### 3. مراجعة دورية
- راجع القواعد بانتظام
- حدد القواعد التي تحتاج تحديث
- احذف القواعد غير المناسبة
- أضف قواعد جديدة حسب الحاجة

### 4. مشاركة الفريق
- شارك التحديثات مع الفريق
- اجمع التغذية الراجعة
- ناقش القواعد الجديدة
- وافق على التحديثات

## الخلاصة

تحديث قواعد المستخدم عملية مستمرة تتطلب مراجعة دورية وتحديث حسب احتياجات المشروع المتطورة. استخدم هذه العملية لضمان فعالية القواعد وتحسين النتائج.
