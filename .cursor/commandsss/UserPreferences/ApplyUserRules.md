# تطبيق قواعد المستخدم

## نظرة عامة
هذا الأمر يساعد في تطبيق قواعد المستخدم المحددة في `AGENTS.md` على جميع التفاعلات مع وكيل Cursor.

## الاستخدام

### تطبيق قواعد التواصل
```
طبق قواعد التواصل المحددة في AGENTS.md:
- استخدم العربية كلغة أساسية
- استخدم الإنجليزية للمصطلحات التقنية
- قدم ردود مفصلة مع أمثلة عملية
- اتبع هيكل الردود المحدد
```

### تطبيق قواعد الترميز
```
طبق قواعد الترميز المحددة في AGENTS.md:
- استخدم TypeScript الصارم
- استخدم meaningful names
- أضف JSDoc للدوال العامة
- استخدم interfaces بدلاً من types
- تجنب استخدام any
```

### تطبيق قواعد المشروع
```
طبق قواعد المشروع المحددة في AGENTS.md:
- اتبع هيكل المجلدات المحدد
- استخدم أنماط التسمية المحددة
- طبق معايير الجودة المحددة
- استخدم الأنماط المحددة للذكاء الاصطناعي
```

## أمثلة على التطبيق

### مثال 1: إنشاء مكون جديد
```
أنشئ مكون React جديد باسم UserProfile مع تطبيق قواعد المستخدم:
- استخدم TypeScript interfaces للـ props
- أضف JSDoc للدوال العامة
- استخدم meaningful names
- اتبع أنماط التسمية المحددة
- أضف error handling شامل
```

### مثال 2: إصلاح خطأ
```
أصلح الخطأ في المكون UserProfile مع تطبيق قواعد المستخدم:
- حدد سبب الخطأ بوضوح
- اشرح كيفية إصلاحه
- قدم كود الإصلاح مع أمثلة
- اشرح كيفية منع تكراره
- اختبر الإصلاح
```

### مثال 3: تطوير ميزة جديدة
```
طور ميزة جديدة مع تطبيق قواعد المستخدم:
- فهم المتطلبات بوضوح
- تصميم الحل وفقاً للأنماط المحددة
- تطوير الكود مع معايير الجودة
- كتابة الاختبارات الشاملة
- توثيق الميزة بشكل مفصل
```

```
- طبق معايير الجودة المحددة

```
