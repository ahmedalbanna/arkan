لقد كشفت سجلات التتبع (Trace) الخاصة بك عن مشكلة شائعة جداً عند محاولة إجبار نماذج LLM صغيرة (مثل `ollama/gemma:2b`) على اتباع تعليمات صارمة ومعقدة، خاصة تلك التي تتضمن **توليد JSON داخل JSON** (في حالتك، توليد نص Markdown معقد داخل حقل في كائن JSON).

### تحليل المشكلة في سجل التتبع

السجل الذي قدمته يوضح أن النموذج فشل في مهمته الأساسية:

1.  **المدخلات (Input):** تم تمرير مطالبة طويلة جداً (بما في ذلك التعليمات الصارمة وهيكل JSON المطلوب) إلى نموذج `gemma:2b`.
2.  **المشكلة:** النموذج لم يولد المحتوى المطلوب (`essay` عن Genkit). بدلاً من ذلك، قام بتكرار أو تلخيص جزء من الهيكل (Schema) الذي تم تمريره له.
3.  **المخرج (Output):**
    ```json
    { "document": "Complete markdown document with proper structure and formatting", "properties": { "documentContent": { "type": "string", "description": "The fully generated document content, formatted as markdown." }, "required": ["documentContent"], "additionalProperties": true, "$schema": "http://json-schema.org/draft-07/schema#" } }
    ```
    النموذج ببساطة أخذ التوجيهات الداخلية المتعلقة بـ Schema وحاول دمجها في مخرجاته، متجاهلاً توليد المقال الفعلي.

### الأسباب الرئيسية للفشل (في سياق Gemma 2B)

1.  **حجم النموذج (2B):** `gemma:2b` هو نموذج "نانو" (Nano model). هو ممتاز للملخصات السريعة أو الإجابات البسيطة، لكنه ضعيف جداً في **الاستدلال المنطقي المعقد** و**الالتزام الصارم بالهياكل المعقدة والطويلة**، خاصة عندما يطلب منه توليد نص طويل (مقالة كاملة) داخل هذا الهيكل.
2.  **تشتت التعليمات (Instruction Overload):** الـ Prompt طويل جداً ويحتوي على تعليمات متناقضة: "أنت خبير" (دور)، "أجب بـ JSON فقط" (تنسيق)، "لا تستخدم backticks" (تنسيق)، "اتبع هذا الـ Schema" (هيكل)، "اكتب مقالاً كاملاً" (محتوى). النماذج الصغيرة تتعرض للارتباك بسرعة مع كثرة القيود.
3.  **الصيغة الصعبة:** طلب توليد **نص Markdown طويل** (نص حر مع تنسيق معقد) داخل **حقل JSON واحد** هو أصعب أنواع المهام على النموذج الصغير.

## الحلول المقترحة لتحسين الأداء

لإصلاح هذه المشكلة وجعل `gemma:2b` يعمل بكفاءة أكبر، يجب علينا تقليل العبء المعرفي والتقني عليه.

### الحل 1: تبسيط الـ Schema والتعليمات

إذا كان هدفك هو فقط الحصول على النص داخل حقل واحد، قم بتبسيط الـ Schema إلى أقصى حد ممكن.

#### التعديل المقترح على الـ Schema:

حذف جميع البيانات الوصفية (Metadata) غير الضرورية التي سببت التشتت:

```json
// Schema المُعدّل (في Genkit)
const SimpleDocumentSchema = z.object({
  document: z.string().describe("The complete essay content formatted in Markdown.")
});
```

#### التعديل المقترح على الـ Prompt (لتقليل الضوضاء):

ركز فقط على المهمة الأساسية والقيود الحرجة:

```markdown
You are an expert writer. Write a comprehensive essay about the relationship between Flow, Prompts, and Tools in Genkit.

CRITICAL INSTRUCTION: Your ENTIRE output must be a valid JSON object matching the requested schema. Do NOT include any text outside the JSON block.

Topic: Genkit: Flow, Prompts, Tools Relationship. Document Type: essay

JSON Output Structure:
{
  "document": "..." // This will contain the full essay in Markdown format.
}
```

### الحل 2: استخدام نموذج أكبر وأكثر كفاءة في JSON

إذا كان التنسيق الصارم (JSON) والمهام المعقدة (كتابة مقال كامل) ضروريين، فإن `gemma:2b` ليس الخيار المناسب.

**التوصية:** قم بتشغيل نموذج أقوى ومناسب لمهام الاستدلال المعقدة، مثل:

*   **Mistral 7B (Quantized):** يتطلب حوالي 4-5 جيجابايت RAM. يعمل بشكل أفضل بكثير على الالتزام بتنسيقات JSON.
*   **Llama 3 8B (Quantized):** نموذج ممتاز حديثاً.

إذا كان جهازك لا يسمح بذلك (8GB RAM فقط)، يجب أن تقبل بأن نموذج 2B قد لا يستطيع توليد المقالات الطويلة داخل هيكل JSON بشكل موثوق.

### الحل 3: تقسيم المهمة داخل Flow (الأكثر موثوقية لـ 2B)

هذه هي الاستراتيجية الأفضل للنماذج الصغيرة: **دع النموذج يقوم بما يبرع فيه، وقم أنت بالعمل الإضافي في Flow.**

1.  **الخطوة 1 (التوليد الحر):** اطلب من `gemma:2b` أن يكتب المقال كاملاً **كنص حر** (بدون قيود JSON).
    *   *الميزة:* هذا يركز قوته المحدودة على جودة الكتابة بدلاً من التحقق من التنسيق.
2.  **الخطوة 2 (التنسيق):** استخدم نموذج آخر **خفيف جداً وموثوق في JSON** (أو حتى كود TypeScript بسيط) لتغليف النص الناتج من الخطوة 1 داخل هيكل JSON المطلوب.

#### مثال على الخطوة 2 (باستخدام TypeScript في Flow):

```typescript
// داخل Flow:

// الخطوة 1: توليد النص
const rawEssayResponse = await generate({
    model: gemma2b,
    prompt: "Write a comprehensive essay about Genkit Flow, Prompts, Tools. Output ONLY the essay text.",
});
const essayText = rawEssayResponse.text;

// الخطوة 2: تغليف النص يدوياً في الهيكل المطلوب
const finalJsonOutput = {
    documentContent: essayText,
};

return finalJsonOutput;
```
هذا يضمن لك الحصول على JSON صالح بنسبة 100% ويقلل من فرص فشل النموذج الصغير.
