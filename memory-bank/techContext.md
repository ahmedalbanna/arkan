# السياق التقني - مشروع Arkan

## المكدس التقني الأساسي

### Frontend
- **Next.js 15**: إطار عمل React مع App Router
- **React 18**: مكتبة واجهة المستخدم مع hooks متقدمة
- **TypeScript**: لغة البرمجة مع type safety
- **Tailwind CSS**: إطار عمل CSS للتصميم
- **Radix UI**: مكونات UI قابلة لإعادة الاستخدام
- **Shadcn UI**: مكتبة مكونات مبنية على Radix UI

### Backend & Infrastructure
- **Firebase**: منصة تطوير متكاملة
  - **Firestore**: قاعدة بيانات NoSQL
  - **Firebase Auth**: نظام المصادقة
  - **Firebase Storage**: تخزين الملفات
  - **Firebase Hosting**: استضافة التطبيق
  - **Cloud Functions**: دوال الخادم
  - **Realtime Database**: قاعدة بيانات في الوقت الفعلي

### الذكاء الاصطناعي
- **Genkit Framework**: إطار عمل Google للذكاء الاصطناعي
- **Google AI Models**: نماذج Gemini (1.5 Flash, Pro, 2.0 Flash)
- **نظام ذكي متقدم**: تحليل السياق واختيار النماذج
- **معالجة المستندات**: PDF, DOCX, PPTX, Markdown

### إدارة الحالة
- **TanStack Query**: إدارة البيانات من الخادم
- **Zustand**: إدارة الحالة المحلية
- **React Context**: مشاركة البيانات بين المكونات

### التطوير والاختبار
- **Jest**: إطار عمل الاختبار
- **Testing Library**: مكتبة اختبار React
- **ESLint**: فحص جودة الكود
- **PostCSS**: معالجة CSS

## المعمارية التقنية

### 1. معمارية المكونات
```
src/
├── app/                    # صفحات Next.js App Router
├── components/             # مكونات UI قابلة لإعادة الاستخدام
├── core/                   # وظائف أساسية قابلة لإعادة الاستخدام
├── hooks/                  # React hooks مخصصة
├── lib/                    # مكتبات مساعدة ونماذج
├── ai/                     # تدفقات الذكاء الاصطناعي والتكوينات
├── services/               # تكاملات الخدمات الخارجية
└── context/                # موفرو React Context
```

### 2. نظام الذكاء الاصطناعي
```
src/ai/
├── core/                   # مكونات النظام الذكي
│   ├── context-analyzer.ts
│   ├── adaptive-model-selector.ts
│   ├── intelligent-prompt-builder.ts
│   ├── output-quality-validator.ts
│   ├── iterative-improvement-engine.ts
│   └── performance-monitor.ts
├── flows/                  # تدفقات الذكاء الاصطناعي
├── schemas/                # مخططات البيانات
├── prompts/                # قوالب المحفزات
└── tools/                  # أدوات مساعدة
```

### 3. إدارة البيانات
- **Firestore**: قاعدة البيانات الرئيسية
- **Realtime Database**: للبيانات الفورية (الإشعارات، الرسائل)
- **Firebase Storage**: للملفات والوسائط
- **TanStack Query**: للـ caching وإدارة البيانات

## الميزات التقنية المتقدمة

### 1. نظام الذكاء الاصطناعي الذكي
- **تحليل السياق**: فهم عميق لمتطلبات المستخدم
- **اختيار النموذج التكيفي**: اختيار ذكي للنماذج حسب المهمة
- **التحسين التكراري**: تحسين تلقائي للمخرجات
- **تقييم الجودة**: تقييم شامل لجودة المخرجات

### 2. معالجة المستندات
- **تحويل PDF**: تحويل PDF إلى Markdown
- **توليد DOCX**: إنشاء مستندات Word
- **توليد PPTX**: إنشاء عروض تقديمية
- **معالجة الصور**: استخراج النص من الصور

### 3. إدارة الحالة المتقدمة
- **TanStack Query**: للبيانات من الخادم مع caching ذكي
- **Zustand**: للحالة المحلية مع persistence
- **React Context**: لمشاركة البيانات بين المكونات

## الأمان والحماية

### 1. أمان البيانات
- **Firebase Security Rules**: قواعد أمان شاملة
- **Authentication**: نظام مصادقة متقدم
- **Input Validation**: التحقق من صحة البيانات مع Zod
- **Environment Variables**: حماية الأسرار

### 2. حماية API
- **Rate Limiting**: حماية من الإساءة (مطلوب تطبيق)
- **CORS**: إعدادات أمان مناسبة
- **Input Sanitization**: تنظيف المدخلات
