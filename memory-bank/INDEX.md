## كيفية الاستخدام

### للمطورين الجدد
1. ابدأ بـ `projectbrief.md` لفهم المشروع
2. اقرأ `techContext.md` للفهم التقني
3. راجع `systemPatterns.md` للأنماط المستخدمة
4. اطلع على `activeContext.md` للحالة الحالية

### للمطورين الموجودين
1. راجع `activeContext.md` للتحديثات
2. اطلع على `recentUpdates.md` للتغييرات الأخيرة
3. راجع `progress.md` لحالة التقدم
4. اطلع على `systemPatterns.md` للأنماط الجديدة

### للمديرين
1. ابدأ بـ `projectbrief.md` للفهم العام
2. راجع `progress.md` لحالة التقدم
3. اطلع على `productContext.md` للسياق المنتج
4. راجع `activeContext.md` للتحديات الحالية

## التحديث

- **تحديث دوري**: شهرياً
- **تحديث عند الحاجة**: عند التغييرات المهمة
- **مراجعة**: راجع المحتوى بانتظام
- **تحسين**: حسن المحتوى باستمرار
