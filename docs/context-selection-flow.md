# مخطط تدفق ميزة تحديد السياق

## تدفق المستخدم

```
1. المستخدم يفتح قسم التقرير
   ↓
2. يرى مؤشر السياق (نقطة خضراء إذا كان هناك سياق محدد)
   ↓
3. ينقر على القسم لفتح التبويبات
   ↓
4. يرى ثلاثة تبويبات:
   - ملخص السياق (افتراضي)
   - إعدادات السياق
   - معاينة السياق
   ↓
5. في تبويب "إعدادات السياق":
   - يحدد عرض المشروع ✓/✗
   - يحدد خطة المشروع ✓/✗
   - يحدد الأقسام الأخرى ✓/✗
   - يحدد الرسوم البيانية ✓/✗
   - يحدد السياق الخارجي ✓/✗
   ↓
6. في تبويب "معاينة السياق":
   - يرى محتوى عرض المشروع
   - يرى محتوى خطة المشروع
   - يرى محتوى الأقسام المحددة
   - يرى محتوى الرسوم البيانية
   - يرى محتوى السياق الخارجي
   ↓
7. في تبويب "ملخص السياق":
   - يرى ملخص سريع للسياق المحدد
   - يرى أيقونات ملونة لكل نوع سياق
   ↓
8. ينقر على زر "إنشاء" لتوليد القسم
   ↓
9. يتم توليد القسم باستخدام السياق المحدد
```

## تدفق البيانات

```
useContextSelector(itemKey)
   ↓
يستقبل itemKey (معرف القسم)
   ↓
يستخدم useGenerationUIStore للحصول على:
- currentSelection (التحديد الحالي)
- toggleContextSelection (دالة التبديل)
   ↓
يستخدم useBuilderStore للحصول على:
- project.proposal (عرض المشروع)
- project.projectPlan (خطة المشروع)
- project.sections (الأقسام المولدة)
- project.diagrams (الرسوم البيانية)
- project.externalContext (السياق الخارجي)
   ↓
يستخدم useSections للحصول على:
- sectionConfigs (تكوين الأقسام)
   ↓
يعيد البيانات المعالجة:
- hasContext (هل هناك سياق محدد)
- selectedSections (الأقسام المحددة)
- selectedDiagrams (الرسوم البيانية المحددة)
- selectedExternalContext (السياق الخارجي المحدد)
```

## هيكل المكونات

```
SectionAccordionItem
├── AccordionTrigger (مع مؤشر السياق)
├── Button (زر الإنشاء)
└── AccordionContent
    └── Tabs
        ├── TabsList
        │   ├── TabsTrigger (ملخص السياق)
        │   ├── TabsTrigger (إعدادات السياق)
        │   └── TabsTrigger (معاينة السياق)
        └── TabsContent
            ├── ContextSummary (ملخص السياق)
            ├── ContextSelector (إعدادات السياق)
            └── ContextViewer (معاينة السياق)
```

## أنواع السياق

```
السياق المحدد
├── عرض المشروع (Project Proposal)
│   ├── أيقونة: FileSpreadsheet
│   ├── لون: أزرق
│   └── مصدر: project.proposal
├── خطة المشروع (Project Plan)
│   ├── أيقونة: GanttChartSquare
│   ├── لون: أخضر
│   └── مصدر: project.projectPlan
├── الأقسام المولدة (Generated Sections)
│   ├── أيقونة: BookCheck
│   ├── لون: بنفسجي
│   └── مصدر: project.sections
├── الرسوم البيانية (Diagrams)
│   ├── أيقونة: GitGraph
│   ├── لون: برتقالي
│   └── مصدر: project.diagrams
└── السياق الخارجي (External Context)
    ├── أيقونة: FileText
    ├── لون: رمادي
    └── مصدر: project.externalContext
```

## حالات الاستخدام

### الحالة 1: لا يوجد سياق محدد
```
المستخدم يفتح قسم جديد
   ↓
لا يرى مؤشر السياق (نقطة خضراء)
   ↓
في تبويب "ملخص السياق" يرى: "لم يتم تحديد سياق لهذا القسم"
   ↓
يمكنه الانتقال إلى "إعدادات السياق" لتحديد السياق
```

### الحالة 2: سياق محدد جزئياً
```
المستخدم حدد عرض المشروع فقط
   ↓
يرى مؤشر السياق (نقطة خضراء)
   ↓
في تبويب "ملخص السياق" يرى: عرض المشروع فقط
   ↓
يمكنه إضافة المزيد من السياق في "إعدادات السياق"
```

### الحالة 3: سياق محدد بالكامل
```
المستخدم حدد جميع أنواع السياق المتاحة
   ↓
يرى مؤشر السياق (نقطة خضراء)
   ↓
في تبويب "ملخص السياق" يرى: جميع أنواع السياق
   ↓
يمكنه معاينة المحتوى في "معاينة السياق"
```

## التكامل مع النظام الحالي

```
النظام الحالي
├── useGenerationUIStore (إدارة حالة UI)
├── useBuilderStore (إدارة حالة المشروع)
├── useContextSelector (hook تحديد السياق)
└── useSections (إدارة الأقسام)

الميزة الجديدة
├── SectionAccordionItem (مكون رئيسي محسن)
├── ContextSelector (مكون تحديد السياق)
├── ContextViewer (مكون معاينة السياق)
└── ContextSummary (مكون ملخص السياق)

التكامل
├── يستخدم النظام الحالي بدون تغييرات
├── يضيف واجهة مستخدم محسنة
├── يحافظ على التوافق مع الكود الموجود
└── يوفر تجربة مستخدم أفضل
```
