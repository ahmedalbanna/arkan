## Overview

This document describes the comprehensive metadata tracking system for sections and projects in the Arkan platform. The system tracks generation status, AI models used, content statistics, version history, and timestamps for all section operations.

---

## Features

### 1. **Section Status Tracking**

Each section tracks its current status through its lifecycle:

```typescript
enum SectionStatus {
  DRAFT = 'draft',           // Not generated yet
  GENERATING = 'generating', // Currently being generated
  GENERATED = 'generated',   // Successfully generated
  FAILED = 'failed',        // Generation failed
  EDITED = 'edited',        // Manually edited after generation
}
```

### 2. **Content Statistics**

Automatically calculated and tracked:
- **Word Count**: Total words in section content
- **Character Count**: Total characters including spaces
- **Estimated Read Time**: Based on 200 words per minute average

### 3. **Generation Metadata**

Tracks AI generation details:
- **AI Model Used**: Which model generated the content (gemma:2b, phi3:mini, llama3:8b, qwen2.5)
- **Generation Timestamp**: When content was generated
- **Generated By**: AI or user (for manual edits)
- **Generation Attempts**: Number of generation attempts (tracks retries)

### 4. **Version History**

Maintains up to 5 previous versions of content:
- Previous content snapshot
- Timestamp of version
- Version number
- Enables content recovery and comparison

### 5. **Timestamps**

Tracks important lifecycle events:
- **createdAt**: When section was created
- **lastModifiedAt**: Last modification timestamp
- **generatedAt**: When AI generation completed

## Section Model Methods

### Status Methods

#### `markAsGenerating(): Section`
Marks section as currently being generated.

```typescript
const section = project.getSection('intro');
const updated = section.markAsGenerating();
// Status: GENERATING
```

#### `markAsGenerated(aiModel: string, content: string): Section`
Marks section as successfully generated with AI model info.

```typescript
const updated = section.markAsGenerated('ollama/gemma:2b', generatedContent);
// Status: GENERATED
// Calculates word count, read time
// Saves version history
// Records AI model used
```

#### `markAsFailed(): Section`
Marks section generation as failed.

```typescript
const updated = section.markAsFailed();
// Status: FAILED
// Increments generation attempts
```

#### `markAsEdited(content: string): Section`
Marks section as manually edited by user.

```typescript
const updated = section.markAsEdited(newContent);
// Status: EDITED
// Saves version history
// Updates statistics
// Sets generatedBy: 'user'
```

### Content Methods

#### `updateContent(content: string, editedByUser?: boolean): Section`
Updates content with optional user edit flag.

```typescript
// Programmatic update (preserves status)
const updated = section.updateContent(newContent, false);

// User edit (changes status to EDITED)
const edited = section.updateContent(newContent, true);
```

### Query Methods

#### `getStatus(): SectionStatus`
Returns current section status.

```typescript
const status = section.getStatus();
if (status === SectionStatus.GENERATING) {
  // Show loading indicator
}
```

#### `isGenerated(): boolean`
Returns true if section has been generated (GENERATED or EDITED).

```typescript
if (section.isGenerated()) {
  // Show regenerate button instead of generate
}
```

#### `isGenerating(): boolean`
Returns true if section is currently being generated.

```typescript
if (section.isGenerating()) {
  // Disable generation button
}
```

#### `getAiModel(): string | undefined`
Returns AI model used for generation.

```typescript
const model = section.getAiModel();
// 'ollama/gemma:2b'
```

#### `getWordCount(): number`
Returns word count from metadata.

```typescript
const words = section.getWordCount();
// 1250
```

#### `getReadTime(): number`
Returns estimated read time in minutes.

```typescript
const minutes = section.getReadTime();
// 6 (minutes)
```

#### `getGeneratedAt(): string | undefined`
Returns generation timestamp.

```typescript
const timestamp = section.getGeneratedAt();
// '2026-01-23T12:34:56.789Z'
```

#### `getGenerationAttempts(): number`
Returns number of generation attempts.

```typescript
const attempts = section.getGenerationAttempts();
// 1 (or higher if retries occurred)
```

## Usage in Generation Flow

### 1. **Start Generation**

```typescript
// In useAiActions hook
const generateSectionMutation = useMutation({
  mutationFn: async (sectionId: string) => {
    // Mark as generating
    updateProject(p => 
      p.updateSection(sectionId, s => s.markAsGenerating())
    );
    
    // Call API
    return await generateReportSectionApi(body, token);
  },
  // ...
});
```

### 2. **Success Handling**

```typescript
onSuccess: (data, sectionId) => {
  const content = data[sectionId];
  const aiModel = data._metadata?.aiModel || 'unknown';
  
  // Mark as generated with model info
  updateProject(p => 
    p.updateSection(sectionId, s => s.markAsGenerated(aiModel, content))
  );
  
  toast({ title: 'Section Generated' });
}
```

### 3. **Error Handling**

```typescript
onError: (error, sectionId) => {
  // Mark as failed
  updateProject(p => 
    p.updateSection(sectionId, s => s.markAsFailed())
  );
  
  toast({ title: 'Generation Failed', variant: 'destructive' });
}
```

## Statistics Calculation

### Word Count
```typescript
function calculateWordCount(content: string): number {
  return content.trim().split(/\s+/).filter(word => word.length > 0).length;
}
```

### Character Count
```typescript
function calculateCharacterCount(content: string): number {
  return content.length;
}
```

### Read Time
```typescript
function calculateReadTime(content: string): number {
  const wordCount = calculateWordCount(content);
  return Math.ceil(wordCount / 200); // 200 words per minute
}
```

## Version History Management

### Adding a Version

When content changes significantly (generation or edit):

```typescript
function addVersionToHistory(
  metadata: SectionMetadata,
  content: string
): SectionMetadata {
  const currentVersion = metadata.version || 1;
  const previousVersions = metadata.previousVersions || [];
  
  // Keep only last 5 versions
  const updatedVersions = [
    {
      content,
      timestamp: new Date().toISOString(),
      version: currentVersion,
    },
    ...previousVersions,
  ].slice(0, 5);
  
  return {
    ...metadata,
    version: currentVersion + 1,
    previousVersions: updatedVersions,
  };
}
```

### Accessing Version History

```typescript
const section = project.getSection('intro');
const metadata = section.metadata as SectionMetadata;

if (metadata.previousVersions && metadata.previousVersions.length > 0) {
  const lastVersion = metadata.previousVersions[0];
  console.log('Previous content:', lastVersion.content);
  console.log('Changed at:', lastVersion.timestamp);
  console.log('Version number:', lastVersion.version);
}
```

## Best Practices

### 1. **Always Use Status Methods**

✅ **Good:**
```typescript
const updated = section.markAsGenerated(aiModel, content);
```

❌ **Bad:**
```typescript
const updated = section.with({ 
  content, 
  metadata: { status: 'generated' } 
});
```

### 2. **Check Status Before Operations**

```typescript
if (section.isGenerating()) {
  // Don't allow another generation
  return;
}

if (section.isGenerated()) {
  // Show "Regenerate" instead of "Generate"
  buttonText = 'Regenerate';
}
```

### 3. **Use Metadata for UI State**

```typescript
// Show word count
<span>{section.getWordCount()} words</span>

// Show read time
<span>{section.getReadTime()} min read</span>

// Show model badge
<Badge>{section.getAiModel()?.split('/')[1]}</Badge>
```

### 4. **Track User Edits**

```typescript
// When user manually edits content
const updated = section.markAsEdited(newContent);

// This preserves the fact that it was user-edited
```

### 5. **Monitor Generation Attempts**

```typescript
const attempts = section.getGenerationAttempts();

if (attempts > 3) {
  // Maybe suggest different parameters
  toast({ 
    title: 'Multiple Attempts', 
    description: 'Consider adjusting section parameters' 
  });
}
```

## Migration Guide

### For Existing Sections

Existing sections without metadata will automatically receive default metadata:

```typescript
{
  status: SectionStatus.DRAFT,
  createdAt: new Date().toISOString(),
  lastModifiedAt: new Date().toISOString(),
  version: 1,
  generationAttempts: 0,
  previousVersions: [],
}
```

### Updating Existing Code

**Before:**
```typescript
updateProject(p => p.updateSection(sectionId, s => s.with({ content })));
```

**After:**
```typescript
updateProject(p => p.updateSection(sectionId, s => s.markAsGenerated(aiModel, content)));
```

## Performance Considerations

### 1. **Version History Limits**

Only the last 5 versions are kept to prevent unbounded growth:

```typescript
const updatedVersions = [...previousVersions].slice(0, 5);
```

### 2. **Statistics Calculation**

Statistics are calculated once during `markAsGenerated()` and cached in metadata, not recalculated on every access:

```typescript
// Efficient: Reads from cached metadata
const wordCount = section.getWordCount();
```

### 3. **Immutable Updates**

All metadata updates return new Section instances (immutable pattern):

```typescript
const updated = section.markAsGenerated(model, content);
// 'section' remains unchanged
// 'updated' is a new instance
```
