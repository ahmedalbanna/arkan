## 📖 مثال استخدام كامل

### سيناريو: كتابة قصة قصيرة

1. **افتح Creative Studio**
   - انتقل إلى `/creative-studio`

2. **اختر نوع المحتوى**
   - اضغط على "قصة"

3. **أدخل معلومات المشروع**
   ```
   العنوان: مغامرة في الصحراء
   المؤلف: أحمد
   النوع: مغامرات
   اللغة: العربية
   ```

4. **اختر قالب** (اختياري)
   - "رحلة البطل" للحصول على بنية جاهزة

5. **ابدأ التوليد خطوة بخطوة**:

   **الخطوة 1: المخطط العام**
   - النبرة: ملهم
   - الطول: 300 كلمة
   - اضغط "توليد"
   - راجع النتيجة → قبول أو إعادة توليد

   **الخطوة 2: تطوير الشخصيات**
   - النبرة: درامي
   - الطول: 400 كلمة
   - تعليمات إضافية: "اجعل البطل شجاعًا ولكن خائفًا من المرتفعات"
   - اضغط "توليد"

   **الخطوة 3: بناء الحبكة**
   - الأسلوب: وصفي
   - الطول: 750 كلمة
   - اضغط "توليد"

   **الخطوة 4: كتابة القصة**
   - النبرة: مشوق
   - الأسلوب: أدبي
   - منظور السرد: الغائب المحدود
   - الطول: 3000 كلمة
   - فعّل "استخدام المستندات المرجعية"
   - اضغط "توليد"

6. **المعاينة والتصدير**
   - انتقل إلى تبويب "المعاينة"
   - راجع القصة الكاملة
   - اضغط "نسخ" أو "تصدير"

## 🔧 التخصيص والتوسع

### إضافة نوع محتوى جديد

1. أضف النوع في `creative-content-config.ts`:
```typescript
export type ContentType = 
  | 'story'
  | 'novel'
  | 'your-new-type'; // 👈 أضف هنا
```

2. أنشئ قالب في نفس الملف:
```typescript
export const YOUR_TEMPLATES: ContentTemplate[] = [
  {
    id: 'your-template',
    name: 'Your Template',
    nameAr: 'القالب الجديد',
    type: 'your-new-type',
    steps: [...],
  },
];
```

3. أضف الكارت في `ContentStudioDashboard.tsx`:
```typescript
const CONTENT_TYPES: ContentTypeOption[] = [
  // ... existing types
  {
    type: 'your-new-type',
    name: 'Your Type',
    nameAr: 'النوع الجديد',
    description: 'Description',
    descriptionAr: 'الوصف',
    icon: YourIcon,
    color: 'text-blue-500',
    gradient: 'from-blue-500/20 to-blue-600/20',
  },
];
```

### إضافة خطوة مخصصة

```typescript
{
  order: 5,
  title: 'Your Custom Step',
  description: 'Description of what this step does',
  type: 'custom',
  config: {
    tone: 'dramatic',
    length: { min: 100, max: 500, target: 300, unit: 'words' },
    additionalOptions: {
      yourCustomOption: 'value',
    },
  },
  optional: false,
}
```

### ربط مع Dynamic Flow

في `generate-step/route.ts`:
```typescript
import { DynamicFlowExecutor } from '@/ai/dynamic-flow';

const flowConfig = {
  name: 'creative-content-generation',
  steps: [
    {
      id: 'generate',
      type: 'llm',
      prompt: prompt,
      config: {
        model: config.modelPreference || 'gemini-2.0-flash-exp',
        temperature: config.temperature || 0.7,
      },
    },
  ],
};

const executor = new DynamicFlowExecutor(flowConfig);
const result = await executor.execute({ input: prompt });
```

## 🐛 استكشاف الأخطاء

### المشروع لا يظهر
تأكد من:
- إضافة الرابط في Navigation
- تشغيل المشروع بـ `npm run dev`
- زيارة الرابط الصحيح

### التوليد لا يعمل
حاليًا يعيد API محتوى تجريبي. لتفعيل التوليد الحقيقي:
1. افتح `generate-step/route.ts`
2. استبدل `generateContent()` بتكامل AI حقيقي
3. استخدم Dynamic Flow أو Genkit مباشرة

### الأخطاء في TypeScript
تأكد من:
- استيراد جميع الأنواع بشكل صحيح
- وجود جميع مكونات UI في `@/components/ui`
