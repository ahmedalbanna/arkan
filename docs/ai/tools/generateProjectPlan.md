
This document outlines the `generateProjectPlan` AI tool.

## Purpose

The `generateProjectPlan` tool enables the `projectChat` agent to create a complete, phase-based project plan by breaking down a high-level project description and list of deliverables.

## How It Works

When a user provides a command like "create a project plan for an e-commerce app where the key deliverables are a product catalog, shopping cart, and payment gateway," the `projectChat` agent understands this as a request to generate a structured plan.

The agent then extracts the `projectDescription` and `keyDeliverables` from the user's message and passes them to this tool. The tool, in turn, calls the main `generateProjectPlan` AI flow, which performs the detailed analysis and generates the full plan object with phases and tasks.

## Parameters

-   **`projectDescription` (string)**: A detailed description of the project, its goals, and its purpose.
-   **`keyDeliverables` (string)**: A summary of the main features or outcomes required for the project.

## Output

The tool returns the full `ProjectPlan` object generated by the AI flow. The client-side application then uses this data to update the `useProjectPlanStore` and render the plan in the UI.
