# مخطط نظام تنظيم السياق المحسن

## تدفق البيانات

```
المستخدم يحدد السياقات
         ↓
useContextSelector يجمع السياقات المحددة
         ↓
useSectionGenerationData يجمع جميع البيانات
         ↓
ContextOrganizer ينظم السياقات حسب المعرفة
         ↓
createOrganizedPrompt ينشئ مطالبة منظمة
         ↓
API يتلقى البيانات المنظمة
         ↓
AI Flow يستخدم السياق المنظم للتوليد
```

## أنواع السياقات المدخلة

```
External Context
├── context (سياق عام)
├── example (أمثلة)
├── question (أسئلة)
├── textbook (محتوى تعليمي)
└── guidelines (إرشادات)

Internal Context
├── selectedSections (أقسام محددة)
└── selectedDiagrams (رسوم بيانية محددة)
```

## تنظيم السياقات حسب المعرفة

```
OrganizedContext
├── guidelines (الإرشادات والتوجيهات) - أولوية عالية
├── foundational (المعرفة الأساسية) - أولوية عالية
├── conceptual (المعرفة المفاهيمية) - أولوية متوسطة
├── procedural (المعرفة الإجرائية) - أولوية متوسطة
├── reference (المراجع الإضافية) - أولوية منخفضة
└── statistics (إحصائيات شاملة)
```

## واجهة المستخدم المحدثة

```
SectionAccordionItem
├── Tab: Summary (ملخص السياق)
├── Tab: Context Settings (إعدادات السياق)
├── Tab: Preview (معاينة السياق)
├── Tab: Organized Context (السياق المنظم) ← جديد
├── Tab: Generation Controls (تحكم التوليد)
└── Tab: Guidelines (الإرشادات)
```

## مؤشرات السياق

```
Context Indicator
├── Green Dot (نقطة خضراء) - سياق محدد
└── Count Badge (عداد) - عدد السياقات المنظمة
```

## مكونات النظام الجديدة

### 1. ContextOrganizer
- **الوظيفة**: تحليل وتنظيم السياقات
- **المدخلات**: قائمة السياقات، القسم المستهدف، متطلبات المستخدم
- **المخرجات**: سياق منظم حسب المعرفة والأولوية

### 2. OrganizedContextDisplay
- **الوظيفة**: عرض السياقات المنظمة في الواجهة
- **الميزات**: ألوان مميزة، إحصائيات، دعم الترجمة

### 3. useSectionGenerationData
- **الوظيفة**: جمع وتنظيم جميع البيانات المطلوبة
- **المخرجات**: بيانات جاهزة للإرسال إلى API

## تحسينات الجودة

### قبل النظام الجديد
- فقط سياقات من نوع `context` تُضمن
- ترتيب عشوائي للسياقات
- عدم وضوح أولوية السياقات

### بعد النظام الجديد
- جميع أنواع السياقات تُضمن
- ترتيب ذكي حسب المعرفة والأهمية
- وضوح كامل في أولوية السياقات
- إحصائيات مفصلة عن السياقات

## مثال على الاستخدام

### 1. تحديد السياقات
```typescript
// المستخدم يحدد:
- مثال من نوع "example"
- سؤال من نوع "question"
- إرشاد من نوع "guidelines"
- قسم داخلي من المشروع
```

### 2. التنظيم التلقائي
```typescript
// النظام ينظمها كالتالي:
guidelines: [الإرشاد المحدد]
foundational: [المعرفة الأساسية من القسم الداخلي]
conceptual: [المثال المحدد]
reference: [السؤال المحدد]
```

### 3. المطالبة المنظمة
```markdown
## 📋 الإرشادات والتوجيهات
### إرشاد 1: [اسم الملف]
[محتوى الإرشاد]

## 🏗️ المعرفة الأساسية
### [اسم القسم الداخلي]
[محتوى القسم]

## 💡 المعرفة المفاهيمية
### [اسم المثال]
[محتوى المثال]

## 📚 المراجع الإضافية
### [اسم السؤال]
[محتوى السؤال]
```

## النتائج المتوقعة

### 1. شمولية السياق
- ✅ جميع أنواع السياقات تُضمن
- ✅ لا توجد سياقات مفقودة
- ✅ تنظيم واضح ومنطقي

### 2. تحسين الجودة
- ✅ مخرجات أفضل من الذكاء الاصطناعي
- ✅ سياق أكثر صلة بالموضوع

### 3. تجربة مستخدم محسنة
- ✅ واجهة واضحة للسياقات المنظمة
- ✅ إحصائيات مفيدة
