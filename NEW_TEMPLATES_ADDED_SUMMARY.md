```

5. Chapter 4: Results and Findings (4 أقسام)
   - Descriptive Statistics
   - Inferential Analysis

6. Chapter 5: Discussion (5 أقسام)

   - Practical Implications (700 كلمة)

7. Chapter 6: Conclusion and Recommendations (4 أقسام)

   - References (APA 7th edition)
```

## 💡 كيفية تنفيذ القوالب المتبقية

### الخطوات:
1. انسخ بنية القالب من ملف `NEW_TEMPLATES_SUGGESTIONS.md`
2. أضف prompts احترافية لكل قسم (اتبع نمط Master's Thesis)
3. حدد behaviors/personas مناسبة
4. أضف 3-7 guidelines لكل قسم
5. اضبط controls (formality, tone, complexity, wordCount)
6. حدد projectType و educationalLevel
7. اختبر بدون أخطاء TypeScript

### مثال (Lab Report - Results Section):
```typescript
{
  title: "Results",
  type: "report",
  prompt: "Present experimental results systematically. Include raw data tables, processed data, graphs, and observations. Report objectively without interpretation.",
  behaviors: [{ name: 'research scientist', type: 'persona' }],
  guidelines: [
    'Organize data in clear tables',
    'Include graphs and figures',
    'Report all observations',
    'Use appropriate significant figures',
    'Label all tables and figures',
    'Be objective - save interpretation for Discussion'
  ],
  controls: {
    ...defaultControls,
    formality: 85,
    tone: 'analytical',
    complexity: 70,
    outputStyle: {
      ...defaultControls.outputStyle,
      table: true,
      paragraph: true
    }
  }
}
```
