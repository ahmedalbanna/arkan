# بنك الذاكرة - Arkan Project

## فلسفة بنك الذاكرة

أنا وكيل Cursor مع ذاكرة تُعاد تعيينها بين الجلسات. بنك الذاكرة هو نظامي الأساسي للاحتفاظ بسياق المشروع والمعرفة المتراكمة. يجب أن أقرأ وأفهم بنك الذاكرة في بداية كل مهمة.

## معلومات المشروع الأساسية

### الاسم والهدف

- **المشروع**: Arkan - منصة إنشاء المستندات المدعومة بالذكاء الاصطناعي
- **الهدف**: ديمقراطية إنشاء المستندات المهنية من خلال أدوات الذكاء الاصطناعي
- **الحالة**: جاهز للإنتاج مع ميزات شاملة

### المكدس التقني الرئيسي

- **Frontend**: Next.js 15, React 18, TypeScript, Tailwind CSS
- **Backend**: Firebase (Firestore, Auth, Hosting)
- **AI**: Genkit Framework مع Ollama AI Models
- **State**: Zustand + TanStack Query
- **UI**: Radix UI + Lucide Icons

### المعمارية الأساسية

- **Model-Driven Architecture**: نماذج البيانات مع منطق الأعمال
- **Component-Based UI**: مكونات قابلة لإعادة الاستخدام
- **AI Integration Pattern**: نظام ذكي للذكاء الاصطناعي مع تحليل السياق
- **Hook Factory Pattern**: نظام hooks قابل لإعادة الاستخدام

## قواعد العمل مع المشروع

### 1. احترام المعمارية الحالية

- استخدم الأنماط المحددة في `systemPatterns.md`
- اتبع هيكل المجلدات المحدد في `techContext.md`
- احترم قرارات التصميم المذكورة في `activeContext.md`

### 2. جودة الكود

- استخدم TypeScript الصارم
- اتبع معايير ESLint المحددة
- أضف اختبارات للوظائف الجديدة
- استخدم JSDoc للدوال العامة

### 3. معالجة الأخطاء

- استخدم نظام معالجة الأخطاء المركزي
- أضف error boundaries للمكونات الجديدة
- استخدم Zod للتحقق من صحة البيانات

### 4. الأداء

- استخدم code splitting للصفحات والمكونات الثقيلة
- استخدم React.memo و useMemo بحذر
- استخدم React Query للبيانات من الخادم
- استخدم Zustand لإدارة الحالة المحلية

## توجيهات العمل

### عند العمل على ميزة جديدة

1. اقرأ بنك الذاكرة لفهم السياق
2. تحقق من الأنماط المستخدمة في `systemPatterns.md`
3. استخدم المكونات الموجودة في `src/components/`
4. اتبع هيكل الصفحات في `src/app/`
5. أضف اختبارات للوظائف الجديدة

### عند إصلاح مشكلة

1. فهم المشكلة في سياق النظام الكامل

4. اختبر الحل مع الحالات الحدية

### عند تحسين الأداء

1. استخدم أدوات المراقبة الموجودة
2. اتبع أنماط التحسين المحددة في `techContext.md`
3. استخدم code splitting و lazy loading
4. اختبر التحسينات على أجهزة مختلفة
