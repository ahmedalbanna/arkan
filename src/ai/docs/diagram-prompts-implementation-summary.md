## 🛠️ الميزات التقنية

### 1. هيكل البرومبتات المتدرج
```typescript
interface DiagramPromptSet {
    system: DiagramPrompt;      // توجيهات النظام والخبرة
    user: DiagramPrompt;        // طلب المستخدم والمتطلبات
    context?: DiagramPrompt;    // السياق والمعلومات الإضافية
    quality?: DiagramPrompt;    // تقييم وتحسين الجودة
    improvement?: DiagramPrompt; // تحسين المخرجات
}
```

### 2. بناء البرومبتات الديناميكي
```typescript
const prompt = await diagramPromptBuilder.buildDiagramPrompt({
    diagramType: 'class',
    title: 'نظام إدارة المكتبة',
    complexity: 'detailed',
    style: { theme: 'modern', direction: 'top-bottom' },
    projectContext: { domain: 'library-management' },
    requirements: ['إدارة الكتب', 'نظام الاستعارة'],
    language: 'ar'
});
```

### 3. معالجة المتغيرات والقوالب
- **استبدال المتغيرات البسيطة**: `{{title}}`, `{{description}}`
- **معالجة القوائم**: `{{requirements}}`, `{{stakeholders}}`
- **السياق الشرطي**: إضافة معلومات حسب التوفر
- **تخصيص اللغة**: دعم العربية والإنجليزية

### 4. إرشادات متخصصة
```typescript
// إرشادات مستوى التعقيد
const complexityGuidelines = {
    basic: 'ركز على العناصر الأساسية والهيكل العام فقط',
    detailed: 'أضف تفاصيل متوسطة مع العلاقات والخصائص المهمة',
    comprehensive: 'اعرض جميع التفاصيل والعلاقات والخصائص بشكل كامل'
};

// إرشادات التصميم
const styleGuidelines = {
    theme: { modern: 'استخدم ألوان حديثة وتصميم عصري' },
    direction: { 'top-bottom': 'رتب العناصر من الأعلى للأسفل' }
};
```

## 📊 أمثلة البرومبتات المولدة

### مثال: مخطط الفئات
```
أنت خبير متخصص في تصميم وتوليد المخططات التقنية باستخدام PlantUML.

تخصصك: مخططات الفئات (Class Diagrams)
- تصميم هياكل الكلاسات والواجهات
- تحديد العلاقات (وراثة، تجميع، ارتباط، تبعية)
- تنظيم الحزم والمساحات
- إظهار الخصائص والطرق بوضوح

أنشئ مخطط فئات لـ: نظام إدارة المكتبة

الوصف: مخطط الفئات الأساسية للنظام
المتطلبات:
- إدارة الكتب والمؤلفين
- تسجيل المستخدمين
- نظام الاستعارة والإرجاع

تأكد من:
- إظهار الفئات الرئيسية مع خصائصها وطرقها
- تحديد العلاقات بوضوح (extends, implements, uses)
- استخدام مستويات الرؤية المناسبة
- تنظيم الفئات في مجموعات منطقية

مستوى التفصيل (detailed): أضف تفاصيل متوسطة مع العلاقات والخصائص المهمة

إرشادات التصميم:
- الثيم: استخدم ألوان حديثة وتصميم عصري
- الاتجاه: رتب العناصر من الأعلى للأسفل
- التفاصيل: اعرض جميع التفاصيل
- الملاحظات: أضف ملاحظات توضيحية

ابدأ بـ @startuml وانته بـ @enduml
```

### مثال: مخطط التسلسل
```
أنت خبير متخصص في تصميم وتوليد المخططات التقنية باستخدام PlantUML.

تخصصك: مخططات التسلسل (Sequence Diagrams)
- تصميم تدفق الرسائل بين الكائنات
- إظهار التفاعلات الزمنية
- استخدام خطوط الحياة والتفعيل

أنشئ مخطط تسلسل لـ: عملية استعارة كتاب

السيناريو: تسلسل العمليات لاستعارة كتاب من المكتبة
الفاعلون: القارئ، نظام المصادقة، قاعدة بيانات الكتب
العمليات: تسجيل دخول، البحث، التحقق من التوفر، تسجيل الاستعارة

تأكد من:
- إظهار جميع الفاعلين والكائنات المشاركة
- ترتيب الرسائل حسب التسلسل الزمني
- استخدام التفعيل للعمليات الطويلة
- وضع أرقام للرسائل للوضوح

ابدأ بـ @startuml وانته بـ @enduml
```
