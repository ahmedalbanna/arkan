# اختبارات نظام الذكاء الاصطناعي المحسن

هذا المجلد يحتوي على اختبارات شاملة لنظام الذكاء الاصطناعي المحسن في مشروع Arkan.

## هيكل الاختبارات

### اختبارات الوحدة (Unit Tests)

#### 1. اختبارات النظام الذكي الرئيسي
- **`intelligent-ai-system.test.ts`** - اختبارات للتدفق الرئيسي للنظام الذكي
  - اختبار `runIntelligentFlow` مع مختلف التكوينات
  - اختبار المكونات المساعدة
  - اختبار معالجة الأخطاء

#### 2. اختبارات تحليل السياق
- **`context-analyzer.test.ts`** - اختبارات لتحليل السياق الذكي
  - اختبار اكتشاف نوع المحتوى
  - اختبار تقييم مستوى التعقيد
  - اختبار تحديد الجمهور المستهدف
  - اختبار تحليل السياق الثقافي
  - اختبار استخراج المتطلبات المحددة
  - اختبار تنظيم السياق المتاح

#### 3. اختبارات اختيار النماذج التكيفي
- **`adaptive-model-selector.test.ts`** - اختبارات لاختيار النماذج التكيفي
  - اختبار اختيار النماذج حسب نوع المهمة
  - اختبار تكوين النماذج (درجة الحرارة، الحد الأقصى للرموز)
  - اختبار التقييم والتصنيف
  - اختبار التوصيات والاستدلال

#### 4. اختبارات بناء المحفزات الذكي
- **`intelligent-prompt-builder.test.ts`** - اختبارات لبناء المحفزات الذكي
  - اختبار بناء المحفزات الأساسية
  - اختبار تحسين المحفزات
  - اختبار المحفزات المتخصصة
  - اختبار معالجة السياق الخارجي

#### 5. اختبارات تقييم جودة المخرجات
- **`output-quality-validator.test.ts`** - اختبارات لتقييم جودة المخرجات
  - اختبار التحقق من جودة المخرجات العالية
  - اختبار تحديد المخرجات منخفضة الجودة
  - اختبار حساب المقاييس
  - اختبار توليد الملاحظات والتوصيات

#### 6. اختبارات محرك التحسين التكراري
- **`iterative-improvement-engine.test.ts`** - اختبارات لمحرك التحسين التكراري
  - اختبار تحسين المخرجات منخفضة الجودة
  - اختبار اختيار استراتيجية التحسين
  - اختبار تطبيق استراتيجية التحسين
  - اختبار تقييم التحسين

#### 7. اختبارات مراقب الأداء
- **`performance-monitor.test.ts`** - اختبارات لمراقب الأداء
  - اختبار بدء وإنهاء الجلسات
  - اختبار تسجيل أوقات المراحل
  - اختبار تسجيل مقاييس الجودة
  - اختبار تسجيل استخدام الموارد
  - اختبار توليد تقارير الأداء

#### 8. اختبارات معالج أخطاء الذكاء الاصطناعي
- **`ai-error-handler.test.ts`** - اختبارات لمعالج أخطاء الذكاء الاصطناعي
  - اختبار معالجة أخطاء انتهاء المهلة
  - اختبار معالجة أخطاء حد المعدل
  - اختبار معالجة أخطاء المصادقة
  - اختبار تصنيف الأخطاء
  - اختبار تحديد الشدة والقابلية للاسترداد

#### 9. اختبارات منظم السياقات
- **`context-organizer.test.ts`** - اختبارات لمنظم السياقات
  - اختبار تنظيم السياق لمختلف المجالات
  - اختبار تصنيف السياق
  - اختبار تحديد أولوية السياق
  - اختبار بناء التسلسل الهرمي للسياق
  - اختبار تحسين السياق للنماذج

## كيفية تشغيل الاختبارات

### تشغيل جميع الاختبارات
```bash
npm test
```

### تشغيل اختبارات محددة
```bash
# اختبارات الوحدة
npm test -- --testPathPattern="unit"

# اختبارات التكامل
npm test -- --testPathPattern="integration"

# اختبار مكون محدد
npm test -- --testPathPattern="context-analyzer"
```

### تشغيل الاختبارات مع التغطية
```bash
npm test -- --coverage
```
