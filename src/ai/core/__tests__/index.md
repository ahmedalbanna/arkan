# فهرس اختبارات نظام الذكاء الاصطناعي المحسن

## نظرة عامة
هذا المجلد يحتوي على اختبارات شاملة لنظام الذكاء الاصطناعي المحسن في مشروع Arkan. تم إنشاء اختبارات للوحدة والتكامل لجميع المكونات الرئيسية.

## الملفات والاختبارات

### 1. اختبارات الوحدة (Unit Tests)

#### `intelligent-ai-system.test.ts`
- **الغرض**: اختبار النظام الذكي الرئيسي
- **الوظائف المختبرة**:
  - `runIntelligentFlow` - التدفق الرئيسي للنظام
  - `analyzeContext` - تحليل السياق
  - `selectModel` - اختيار النموذج
  - `buildPrompt` - بناء المحفز
  - `validateOutput` - التحقق من المخرجات
  - `improveOutput` - تحسين المخرجات
- **عدد الاختبارات**: 15+ اختبار
- **الحالات المختبرة**: التدفق العادي، الأخطاء، الحالات الحدية

#### `context-analyzer.test.ts`
- **الغرض**: اختبار تحليل السياق الذكي
- **الوظائف المختبرة**:
  - `analyzeContext` - التحليل الرئيسي للسياق
  - `detectContentType` - اكتشاف نوع المحتوى
  - `assessComplexity` - تقييم مستوى التعقيد
  - `identifyTargetAudience` - تحديد الجمهور المستهدف
  - `analyzeCulturalContext` - تحليل السياق الثقافي
  - `extractRequirements` - استخراج المتطلبات
  - `organizeAvailableContext` - تنظيم السياق المتاح
- **عدد الاختبارات**: 20+ اختبار
- **المجالات المختبرة**: تجاري، تقني، أكاديمي، إبداعي

#### `adaptive-model-selector.test.ts`
- **الغرض**: اختبار اختيار النماذج التكيفي
- **الوظائف المختبرة**:
  - `selectOptimalModel` - اختيار النموذج الأمثل
  - `evaluateModels` - تقييم النماذج
  - `scoreModel` - تصنيف النماذج
  - `configureModel` - تكوين النموذج
  - `getModelRecommendation` - الحصول على التوصية
- **عدد الاختبارات**: 25+ اختبار
- **النماذج المختبرة**: gemini-pro, gemini-pro-vision, gemini-flash

#### `intelligent-prompt-builder.test.ts`
- **الغرض**: اختبار بناء المحفزات الذكي
- **الوظائف المختبرة**:
  - `buildPrompt` - بناء المحفز الرئيسي
  - `buildSystemPrompt` - بناء محفز النظام
  - `buildUserPrompt` - بناء محفز المستخدم
  - `buildContextPrompt` - بناء محفز السياق
  - `buildGuidelinesPrompt` - بناء محفز الإرشادات
  - `optimizePrompt` - تحسين المحفز
- **عدد الاختبارات**: 20+ اختبار
- **الأنواع المختبرة**: أساسي، محسن، متخصص

#### `output-quality-validator.test.ts`
- **الغرض**: اختبار تقييم جودة المخرجات
- **الوظائف المختبرة**:
  - `validateOutput` - التحقق من المخرجات
  - `calculateMetrics` - حساب المقاييس
  - `generateFeedback` - توليد الملاحظات
  - `generateImprovementSuggestions` - توليد اقتراحات التحسين
- **عدد الاختبارات**: 15+ اختبار
- **المقاييس المختبرة**: الصلة، التماسك، الاكتمال، الوضوح، الدقة

#### `iterative-improvement-engine.test.ts`
- **الغرض**: اختبار محرك التحسين التكراري
- **الوظائف المختبرة**:
  - `improveOutput` - تحسين المخرجات
  - `selectImprovementStrategy` - اختيار استراتيجية التحسين
  - `applyImprovementStrategy` - تطبيق استراتيجية التحسين
  - `evaluateImprovement` - تقييم التحسين
- **عدد الاختبارات**: 20+ اختبار
- **الاستراتيجيات المختبرة**: توسيع، تحسين، تنقيح، إعادة هيكلة

#### `performance-monitor.test.ts`
- **الغرض**: اختبار مراقب الأداء
- **الوظائف المختبرة**:
  - `startSession` - بدء الجلسة
  - `endSession` - إنهاء الجلسة
  - `recordPhaseTime` - تسجيل وقت المرحلة
  - `recordQualityMetrics` - تسجيل مقاييس الجودة
  - `recordResourceUsage` - تسجيل استخدام الموارد
  - `recordError` - تسجيل الخطأ
  - `recordFallbackUsage` - تسجيل استخدام الخطة الاحتياطية
  - `generatePerformanceReport` - توليد تقرير الأداء
  - `exportData` - تصدير البيانات
  - `clearOldData` - مسح البيانات القديمة
  - `getQuickStats` - الحصول على إحصائيات سريعة
- **عدد الاختبارات**: 25+ اختبار
- **المقاييس المختبرة**: الوقت، الجودة، الموارد، الأخطاء

#### `ai-error-handler.test.ts`
- **الغرض**: اختبار معالج أخطاء الذكاء الاصطناعي
- **الوظائف المختبرة**:
  - `handleError` - معالجة الخطأ
  - `classifyError` - تصنيف الخطأ
  - `determineSeverity` - تحديد الشدة
  - `isRecoverable` - تحديد القابلية للاسترداد
  - `getRecoveryStrategy` - الحصول على استراتيجية الاسترداد
  - `generateUserMessage` - توليد رسالة المستخدم
  - `generateTechnicalDetails` - توليد التفاصيل التقنية
  - `generateSuggestedActions` - توليد الإجراءات المقترحة
- **عدد الاختبارات**: 30+ اختبار
- **أنواع الأخطاء المختبرة**: انتهاء المهلة، حد المعدل، المصادقة، النموذج غير موجود، سياسة المحتوى، الشبكة، غير معروف

#### `context-organizer.test.ts`
- **الغرض**: اختبار منظم السياقات
- **الوظائف المختبرة**:
  - `organizeContext` - تنظيم السياق
  - `categorizeContext` - تصنيف السياق
  - `prioritizeContext` - تحديد أولوية السياق
  - `buildContextHierarchy` - بناء التسلسل الهرمي للسياق
  - `optimizeContextForModel` - تحسين السياق للنموذج
- **عدد الاختبارات**: 20+ اختبار
- **المجالات المختبرة**: تجاري، تقني، أكاديمي، إبداعي، عام
