This document outlines the AI Content Detector tool.

## Purpose

The AI Content Detector is designed to analyze a piece of text and estimate the probability that it was generated by an AI model. It helps users identify content that may lack a human touch or originality.

## Key Concepts

-   **AI Flow**: Wraps the `detectAiContent` Genkit flow from `src/ai/flows/detect-ai-content.ts`.
-   **Probabilistic Scoring**: The tool doesn't give a definitive "yes" or "no." Instead, it provides a percentage score based on patterns like sentence structure uniformity, lack of personal voice, and repetitiveness, which are often characteristic of AI-generated text.
-   **Analysis**: Alongside the score, it provides a brief textual analysis explaining the reasoning behind its conclusion.

## Workflow

1.  A user navigates to the "AI Detector" page.
2.  They paste their text into the text area.
3.  Upon clicking "Analyze Text," the frontend calls the `/api/ai/writing-tools/ai-detector` endpoint.
4.  The API route invokes the `detectAiContent` flow, which prompts the AI model to perform the analysis.
5.  The structured result, containing the `score` and `analysis`, is returned to the client and displayed in the UI.
